# zMenu+

**zMenu+** 是 zMenu 的高级付费扩展插件，添加了强大的进阶功能，以提升您的库存创建体验。

## 什么是 zMenu+？

zMenu+ 在免费版 zMenu 插件的基础上扩展了更多功能，专为希望在菜单中获得更强控制力和功能性的服务器所有者设计。

:::tip 支持免费开发
购买 zMenu+ 有助于让 zMenu 对**所有人保持免费**。您的支持使开发者能够持续改进免费版本，让成千上万的服务器从中受益。
:::

## 功能特性

zMenu+ 包含免费版中不可用的专属功能：

### 高级按钮类型
更多按钮类型，支持更复杂的菜单行为。

### 增强型动作
额外的动作类型，打造更具交互性的菜单。

### 优先支持
zMenu+ 用户享有优先技术支持。

### 早期访问
在免费版发布前抢先体验新功能。

## 安装步骤

1. 从上方链接购买并下载 zMenu+
2. 确保服务器已安装 zMenu
3. 将 zMenu+ 的 JAR 文件放入 `plugins/` 文件夹
4. 重启服务器

:::info 需要 zMenu 基础插件
zMenu+ 是扩展插件，必须配合基础版 zMenu 才能运行。请先确保已安装 zMenu。
:::

## 常见问题

### 使用 zMenu 是否必须购买 zMenu+？

不需要。zMenu 作为免费插件功能完整。zMenu+ 是可选扩展，仅提供额外功能。

### 购买前能否试用 zMenu+？

加入 Discord 服务器，查看示例并咨询 zMenu+ 提供的具体功能。

### 是否提供退款？

请查阅 Minecraft Inventory Builder 网站的退款政策。

### 现有库存配置能否与 zMenu+ 兼容？

完全兼容！zMenu+ 与您现有的 zMenu 配置 100% 兼容。它仅添加新功能，不会改变现有功能的工作方式。
